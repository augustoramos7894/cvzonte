# CVzonte 
**CVzonte** é um construtor de currículos inteligente inspirado na experiência de ferramentas como Canva e LinkedIn. Desenvolvido com **Next.js**, **React**, **TypeScript** e **Tailwind CSS**, o projeto utiliza uma arquitetura modular para gerar currículos profissionais com preview em tempo real, sugestões automáticas de competências, resumos personalizados e estrutura otimizada para ATS. A longo prazo, o objetivo é evoluir para uma plataforma completa de carreira, incorporando recursos de IA, análise de currículos, recomendações personalizadas e auxílio na preparação para processos seletivos.
